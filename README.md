# 서울에이스정형외과의원 홈페이지 리뉴얼 시안

강릉 서울에이스정형외과의원의 홈페이지 리뉴얼 시안입니다. Next.js(App Router) + TypeScript로 만들었고 Vercel 배포를 전제로 합니다.

## 페이지 구성

| 경로 | 파일 | 내용 |
|---|---|---|
| `/` | `app/page.tsx` | 메인 — 진료 철학, 증상 요약, 두개경추 접합부 소개, 치료 방법, 진료 안내 |
| `/symptoms` | `app/symptoms/page.tsx` | 증상과 치료 — 허리 / 무릎·어깨 / 두통·이명·어지럼 / 팔다리 저림 |
| `/about` | `app/about/page.tsx` | 병원 소개 — 원장 인사말, 진료 원칙, 공간, 타 지역 내원 안내, 오시는 길 |

## 어디를 고치면 되나

- **병원 정보(전화·주소·진료시간)** → `lib/site.ts` 한 파일만 고치면 세 페이지에 모두 반영됩니다.
- **색·글꼴·여백** → `app/globals.css` 맨 위의 `:root` 토큰
- **본문 문구** → 각 페이지 파일 안에 그대로 한글로 들어 있습니다
- **사진** → `public/images/` 에 넣고, `<Placeholder ... />` 를 `<img src="/images/파일명.jpg" alt="설명" />` 로 바꾸면 됩니다

## 실행 방법

Node.js 20 이상이 필요합니다. (현재 이 PC에는 설치되어 있지 않습니다)

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 으로 접속합니다.

## Vercel 배포

1. 이 폴더를 GitHub 저장소로 올립니다.
2. [vercel.com](https://vercel.com) → **Add New → Project** → 해당 저장소 선택
3. 프레임워크는 **Next.js**로 자동 인식됩니다. 설정을 바꿀 것 없이 **Deploy**.
4. 배포 후 Settings → Domains 에서 `seoulaceos.co.kr` 연결이 가능합니다.
   (기존 사이트가 운영 중이므로, 시안 검토가 끝난 뒤에 도메인을 옮기세요.)
